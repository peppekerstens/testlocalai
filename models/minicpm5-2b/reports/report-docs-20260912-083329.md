  Exact diff: the model inserted an extra line, `Line 16 is exactly this note
  line:`, right before the note it was supposed to reproduce verbatim —
  meta-commentary about the task, not present in the source. New idiom for
  this model: adds an explanatory aside inside a verbatim-reproduction task.
  `finish_reason: stop`, not a truncation. Single draw, not a reliability
  sample.
- **`doc-script`**: `verify.sh` reports `bash -n: FAIL` (`unexpected EOF while
  looking for matching ')'`) — the emitted script is not valid bash.
  `finish_reason: length` at 16384 completion tokens — genuinely
  truncated-by-context-limit, not a content failure on its own terms. The
  script cuts off mid-statement. New idiom: this model's default thinking
  mode can consume a large share of the completion budget before the real
  answer starts, leaving a long output (a full bash script here) without
  enough room to finish. Same general shape as `deepseek-r1-1.5b`'s
  documented runaway-reasoning idiom (`models/deepseek-r1-1.5b/history.md`),
  not identical mechanism. Single draw — unknown whether this recurs.
- **`doc-repair`**: `verify.sh` reports `content match (whitespace-normalized):
  FAIL`, and the diagnostic byte-exact diff shows the visible answer content
  is close to empty. `finish_reason: length` at 16384 — truncated, and worse
  than `doc-script` here: the reasoning phase appears to have consumed
  essentially the entire budget, leaving little to nothing for the actual
  fix. Same idiom as `doc-script`, more severe. Single draw.
- **Sample-size caveat, whole report**: every result above is one draw
  (`n=1`), not a reliability sample. A second pass could land differently,
  especially on the two truncated tasks — this model's own default
  temperature/thinking behavior was not touched.
