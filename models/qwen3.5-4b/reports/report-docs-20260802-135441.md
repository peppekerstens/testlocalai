"text tasks" sampling preset (`DISPATCH_TEMPERATURE=1.0
DISPATCH_TOP_P=0.95 DISPATCH_TOP_K=20 DISPATCH_PRESENCE_PENALTY=1.5`),
no `enable_thinking` override (this model doesn't need it — see

any qwen3.5 config tested this session (0.8B: 1/9, 2B: 2/9). Single
draw throughout — every verdict below is n=1, not yet a rate.

**Critical finding, not a content-quality issue: 4 of 9 tasks hit
`finish_reason=length` and produced completely empty final content**
(`doc-verbatim`, `doc-adapt`, `doc-script`, `doc-repair` — all 4
truncated at 7169-7773 completion tokens, all with zero-length actual
output). **Truncation judgment (per `AGENTS.md`'s required check):
this is NOT the known deepseek-r1-style rare-tail-event pattern** —
that was documented as occasional/rare and unaffected by raising
context size. This is **44% of tasks in a single draw**, far above any
previously documented rate in this project, and directly contradicts
the earlier 3/3-clean smoke test on trivial prompts (confirmed via
direct `journalctl` monitoring during this exact run — task 34639 hit
`n_tokens=8191, truncated=1` after 210.9s; task 24507 likewise;
task 46532 came within 314 tokens of the same ceiling before narrowly
converging, contributing to `doc-crossref`'s PASS at 7087/8192
completion tokens). **Reference timing established during this run**:
a normal, non-runaway completion takes ~15-45s; a genuine runaway that
exhausts the full 8192-token context takes ~211s, at this model's
observed ~37-40 tok/s generation speed.

**These are not diagnosable as content idioms** — an empty final
answer carries no content signal to classify (Idiom Q1-Q5 from the
smaller configs don't apply; there is nothing to compare against
`expected.md` beyond "nothing was produced"). The only lever that
matters for these 4 tasks is context/thinking-length management, not
prompt-level content steering.

**The 5 PASSes are real** (`doc-surgical`, `doc-synthesize`,
`doc-summarize`, `doc-crossref`, `doc-restructure`) — genuine content
correctness, not truncation-adjacent near-misses, except
`doc-crossref`'s narrow margin noted above.

   `DISPATCH_ENABLE_THINKING=false`** for this model. Two concrete
