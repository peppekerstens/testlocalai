TypeScript/Node was chosen over Python because every existing ConnectWise MCP server surveyed, and the official `@modelcontextprotocol/sdk` this project depends on, are TypeScript/Node. That decision later proved valuable: research into auth found a team dropping Python because the MCP TypeScript SDK offered built-in OAuth support Python's SDK lacked. Staying on this stack also lets the project reuse TypeScript/Node-based Entra ID/Azure research already gathered for its planned auth work.
