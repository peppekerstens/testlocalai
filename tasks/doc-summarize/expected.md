The server is built in TypeScript/Node, not Python. That matched the official MCP SDK — the most actively maintained reference implementation of the spec — and every existing ConnectWise MCP server surveyed, all of which are also TypeScript/Node. It also paid off later: the TypeScript SDK ships first-class OAuth primitives that the Python SDK lacked, and the Entra ID/Azure auth research this project drew on is TypeScript-based too.
